# JellyMacro

A powerful macro automation tool for Roblox, featuring screen capture, action recording, image recognition, and Discord webhook integration.

## Quick Start

Download the pre-built executable from `dist/JellyMacro.exe` or build from source:

```bash
pip install -r requirements.txt
python run.py
```

See `JellyMacro/README.md` for detailed documentation.

## Features

- Screen capture with 800x800 canvas for consistent image recognition
- Action recording and playback (clicks, keystrokes, waits)
- Conditional actions (if image visible, check for picture)
- Image recognition with screenshot collection tool
- Counter system for tracking gems, tokens, etc.
- Discord webhook integration (screenshots every 30 min)
- Dark/Light theme support
- Cross-platform (Windows, macOS, Linux)
